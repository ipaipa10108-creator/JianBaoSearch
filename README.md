# 健保支付標準與 ICD 編碼查詢系統 (JianBaoSearch)

整合衛生福利部中央健康保險署「全民健康保險醫療服務給付項目及支付標準」、**ICD-9 / ICD-10-CM / ICD-11 診斷編碼對照**、**ICD-10-PCS 處置編碼查詢** 與 **AI 自然語言跨庫智慧查詢**，支援 **PWA 安裝與離線使用**、**每日自動同步最新健保署開放資料**，並可 100% 免費部署至 **Cloudflare Pages**、**Vercel** 或 **GitHub Pages**。

## 主要功能

### 1. 健保支付標準查詢（NHI）
- **多關鍵字即時搜尋**：支援同時搜尋診療項目代碼、中文項目名稱、英文項目名稱、部章節與備註（多關鍵字以空格分隔，例如：`超音波 腹部`、`2-2-7`），並支援 `/` 快捷鍵聚焦搜尋框。
- **部章節與表別篩選**：依代碼自動對應完整**部章節**名稱（如 `第二部第二章第六節 治療處置`、`第二部第二章第七節 手術-胸腔`），於外部列表卡片、桌面表格及詳細抽屜皆有標注；支援依表別（`C 含基層診所`、`B 醫院`、`A 醫學中心/區域`、`P 專案計畫`、`其他`）、部章節與現行有效狀態篩選，並可依相關度、代碼、點數高低或最新生效日排序。
- **詳細規範與常用收藏**：點擊項目可開啟詳細抽屜檢視自動分行的備註規範，支援一鍵複製代碼／完整資訊、常用星號收藏（★，儲存於瀏覽器本機）與匯出 CSV。

### 2. ICD-9 / ICD-10-CM / ICD-11 診斷編碼對照（DX）
- **三版本同步對照**：輸入任一版本的代碼（如 `250.00`、`E11.9`、`5A11`）或中英文疾病名稱（如 `糖尿病`、`高血壓`），即同時列出對應的 **ICD-9-CM**、**ICD-10-CM**（含健保署中英文名稱）與 **WHO ICD-11** 編碼。
- 支援僅顯示含 ICD-11 對應項目篩選、一鍵複製任一版本代碼與匯出 CSV。

### 3. ICD-10-PCS 處置編碼查詢（PCS）
- **處置碼與健保醫令串聯**：支援搜尋 **ICD-10-PCS** 處置代碼、中英文處置名稱、對應 **ICD-9-CM 處置碼**及**健保醫令碼**。
- 點擊結果卡片上的「對應健保醫令」按鈕，可直接跳轉回「健保支付標準查詢」分頁檢視該醫令的支付點數與申報規範。

### 4. AI 自然語言跨庫查詢與歷史紀錄（AI）
- **聚焦醫學編碼與客觀理賠要件的 AI 顧問角色**：嚴格依據臨床事實提供正確的診斷碼與處置碼，客觀檢視健保部章節（如 `2-2-7` 手術 vs `2-2-6` 治療處置）與保險理賠要件的符合程度，並嚴守「**絕不為了迎合保險理賠而扭曲診斷**」之醫學倫理原則。
- **多元 AI 供應商、免費模型搜尋與最近模型快切**：於頂端列 **設定齒輪（⚙）** 可獨立設定 **Google Gemini**、**OpenRouter**、**OpenAI** 與 **自訂（OpenAI 相容 API）** 的 API Key；其中 **Gemini** 與 **OpenRouter** 支援一鍵 **「自動搜尋 Free Model」**（所有 Key 僅儲存於瀏覽器本機 `localStorage`），並可於 AI 頁面點擊**目前模型代號**快速切換最近使用過的模型。
- **主畫面快速啟用、反問機制與背景續傳**：勾選主畫面搜尋框下方的 **「啟用 AI搜尋」** 即可用自然語言一次查詢 **健保支付標準**、**ICD-9/10/11 診斷** 與 **ICD-10-PCS 處置編碼**；支援 **「允許 AI 反問必要性問題」** 開關（條件不足時先追問關鍵臨床資訊）、即時進度條與耗時計時、背景持續查詢，以及手機切換 App 返回後自動續傳中斷的查詢。
- **編碼依據說明、繼續對話與長結果滑動快捷列**：每次查詢結果下方皆附有編碼依據說明（說明為何列出各健保項目、ICD 診斷、ICD 處置，以及後續要件與可能發展）與**多輪繼續追問對話**；檢視長串 AI 結果往下滑動時，畫面底部會自動浮現三個快速功能鍵（**回到歷史查詢**／**顯示判斷原因**／**繼續對話**）方便快速定位。
- **歷史紀錄卡牌快捷鍵與醫令彈窗檢視**：頂端列提供 **「AI查詢歷史」** 快捷入口，每張已完成查詢的歷史卡牌下方皆提供 **「顯示判斷原因」** 與 **「繼續對話」** 按鈕，點擊即可直達對應區塊，並支援個別單筆刪除與全部清空；此外，點擊 AI 查詢結果中的「對應健保醫令」時，會直接彈出該醫令的詳細資訊視窗（附關閉按鈕），檢視點數與申報規範不須跳頁或重新捲動。

### 5. 設定匯入 / 匯出與個人化體驗
- **完整設定備份與還原**：於設定視窗可一鍵 **匯出／匯入 JSON**，包含各供應商的 **AI API Key 與模型設定**、**AI 查詢歷史紀錄**、**常用星號收藏（★）**、**明亮/暗色主題**與**字型大小設定**。
- **明亮 / 暗色模式與 A+ / A- 字型縮放**：支援一鍵切換明亮與暗色主題，並提供 `13px`～`22px` 全站等比例字型縮放，適合手機、平板、桌面及電子紙閱讀器使用。
- **PWA 與書籤圖示**：內建 [`manifest.json`](manifest.json)、[`sw.js`](sw.js) 離線快取與 `icons/` 專屬醫療放大鏡圖示，可安裝至手機桌面或電腦應用程式。

## 資料來源與自動更新機制

- **健保支付標準**：[政府資料開放平臺－醫療服務給付項目及支付標準 (174450)](https://data.gov.tw/dataset/174450)
  - 更新腳本：[`scripts/update_data.py`](scripts/update_data.py)
  - 排程工作流程：[`.github/workflows/update-nhi-data.yml`](.github/workflows/update-nhi-data.yml)（每日台灣時間 `09:00` 自動檢查更新並推送至 `main`）
- **ICD 對照資料**：健保署 2001 年版 ICD-9-CM 與 2023 年版 ICD-10-CM/PCS 對應檔、ICD-10-PCS 與健保醫令對應檔（透過 [`scripts/build_icd_data.py`](scripts/build_icd_data.py) 建置），以及 WHO 官方 ICD-10 與 ICD-11 對照表。

## 免費部署方式

本專案為純靜態網頁（無須建置指令），以下平台皆提供免費方案：

- **Cloudflare Pages**：連結此 GitHub Repo，Build command 留空，Build output directory 設為 `/`（根目錄）。
- **Vercel**：匯入此 GitHub Repo，Framework Preset 選 `Other`，不需設定 Build Command，直接部署即可。
- **GitHub Pages**：至 Repo 的 **Settings → Pages**，選擇 `Deploy from a branch`（`main` / `/ (root)`）。
